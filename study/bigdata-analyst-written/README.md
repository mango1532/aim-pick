# 빅데이터분석기사 필기 400제

최근 출제 흐름과 공식 출제범위를 바탕으로 새로 만든 4지선다형 대비 문제입니다. 실제 기출문제를 그대로 복원하거나 복제한 자료가 아닙니다.

## 구성

- `subject-1-planning.md`: 1과목 빅데이터 분석기획 100문제
- `subject-2-exploration.md`: 2과목 빅데이터 탐색 100문제
- `subject-3-modeling.md`: 3과목 빅데이터 모델링 100문제
- `subject-4-interpretation.md`: 4과목 빅데이터 결과 해석 100문제
- `answer-sheet.md`: 회차별 답안지

각 과목 파일은 앞부분의 문제편과 뒷부분의 정답·핵심 해설로 구성됩니다.

## 2주 활용법

1. D-14~D-11: 과목별 1~50번을 하루 한 과목씩 풉니다.
2. D-10~D-7: 과목별 51~100번을 하루 한 과목씩 풉니다.
3. D-6~D-3: 아래 실전 세트 네 개를 매일 하나씩 120분 이내에 풉니다.
4. D-2: 틀린 문제와 헷갈렸던 선지만 다시 풉니다.
5. D-1: 해설의 핵심 문장과 공식을 가볍게 확인합니다.

## 실전 세트

각 세트는 실제 시험과 동일하게 과목당 20문제, 총 80문제입니다.

| 세트 | 각 과목 문항 |
|---|---|
| A | 1~20 |
| B | 21~40 |
| C | 41~60 |
| D | 61~80 |
| 최종 보충 | 81~100 |

채점 시 전체 48문제 이상이면서 모든 과목에서 8문제 이상을 맞혀야 합격 기준을 충족합니다. 안정권 목표는 전체 56문제 이상, 과목별 11문제 이상입니다.

## 오답 분류

- `A`: 개념 자체를 몰랐음
- `B`: 비슷한 개념을 혼동함
- `C`: 계산 또는 조건을 잘못 읽음
- `D`: 맞혔지만 확신이 없었음

`A·B`는 해당 단원을 다시 정리하고, `C·D`는 문제와 모든 선지를 다시 설명해 보는 방식으로 복습합니다.
