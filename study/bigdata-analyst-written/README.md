# 빅데이터분석기사 필기 400제

최근 출제 흐름과 공식 출제범위를 바탕으로 새로 만든 4지선다형 대비 문제입니다. 실제 기출문제를 그대로 복원하거나 복제한 자료가 아닙니다.

## 구성

- `subject-1-planning.md`: 1과목 빅데이터 분석기획 100문제
- `subject-2-exploration.md`: 2과목 빅데이터 탐색 100문제
- `subject-3-modeling.md`: 3과목 빅데이터 모델링 100문제
- `subject-4-interpretation.md`: 4과목 빅데이터 결과 해석 100문제
- `answer-sheet.md`: 회차별 답안지

각 과목 파일은 앞부분의 문제편과 뒷부분의 정답·핵심 해설로 구성됩니다.

## 최신 경향 반영

공식 기출문제가 공개되지 않으므로 특정 회차의 문항 수나 비공식 합격률을 문제의 근거로 사용하지 않았습니다. 공식 출제범위와 최근 복원 자료·수험 후기에서 강조되는 주제를 참고해 다음 영역을 보강했습니다.

- 용어 암기보다 조건·가정·장단점을 구분하는 이해형 문제 강화
- 가설검정의 절차와 검정 선택, 유의수준·p값 해석 강화
- 신경망, Attention, Transformer와 옵티마이저 강화
- 배깅·부스팅뿐 아니라 스태킹·블렌딩까지 앙상블 범위 확장
- 자카드 유사도, SVM, 나이브베이즈, 연관분석, SVD·고유값분해, ACF, HMM 반영
- 랜덤 서브 샘플링, 하이퍼파라미터 탐색, 데이터 리니지, 평행좌표 반영

추가로 제공된 `11·12회 실제 풀이 반영 신규 90제`도 비교했습니다. 이 자료 역시 실제 시험 원문이 아니라 강의에서 확인한 개념·계산 패턴을 새 숫자와 문장으로 재구성한 연습문제라고 명시되어 있으므로, 다음 출제영역만 추출해 현재 문제를 새 문항으로 보강했습니다.

- HDFS·GFS·Ceph와 HBase의 역할 구분
- 부호검정, 검정력, 결측 메커니즘과 변환 방법
- Wald 검정, AIC, Ward 연결법
- GBM·XGBoost·LightGBM, MCMC·Gibbs sampling·Burn-in
- F-beta, MPE·MAPE, 상대위험도·오즈비, ANOVA 평균제곱과 F값

## 개념 연결 순서

빠른 이해를 위한 권장 문제풀이 순서는 `3과목 → 4과목 → 2과목 → 1과목`입니다. 먼저 모델을 배우고 평가·개선 방법을 연결한 다음, 그 모델에 들어갈 데이터를 어떻게 탐색·전처리하며 전체 분석을 어떻게 기획하는지 역순으로 확장합니다.

실제 업무 흐름은 다음처럼 구분해 두세요.

`기획 → 원데이터 수집 → 분할 원칙 확정 → train/validation/test 분할 → 학습 데이터 중심 EDA → 학습 데이터로 전처리 기준 적합 → 모델링 → 평가·개선 → 시각화·활용 → 모니터링·리모델링`

검증·테스트 데이터에는 학습 데이터에서 정한 전처리 기준을 변환만 적용해야 합니다. 전체 데이터로 결측치 대체값·스케일·변수 선택 기준을 먼저 계산하면 데이터 누출이 생길 수 있습니다.

함께 구분해야 할 핵심 축:

- 지도학습(회귀·분류), 비지도학습(군집·차원축소·연관규칙), 준지도학습, 강화학습
- Holdout, K-fold, LOOCV, 랜덤 서브 샘플링, Bootstrap
- 과적합·과소적합과 편향-분산 트레이드오프
- 회귀 지표(MAE·MSE·RMSE·R²)와 분류 지표(Accuracy·Recall·Specificity·Precision·F1·ROC-AUC)

혼동행렬은 예측값으로 뒤 글자 `P/N`을 먼저 정하고, 실제값과 일치하면 `T`, 다르면 `F`를 앞에 붙이면 됩니다.

## 오답 분류

- `A`: 개념 자체를 몰랐음
- `B`: 비슷한 개념을 혼동함
- `C`: 계산 또는 조건을 잘못 읽음
- `D`: 맞혔지만 확신이 없었음

`A·B`는 해당 단원을 다시 정리하고, `C·D`는 문제와 모든 선지를 다시 설명해 보는 방식으로 복습합니다.
