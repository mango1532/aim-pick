MINI 문항 이미지 (public/images/mini)

  01.png ~ 12.png  (또는 01.jfif ~ 12.jfif)

권장: PNG 또는 JPG (브라우저 호환성 좋음)
JFIF 사용 시 아래 두 폴더 모두에 넣어 주세요:
  - public/images/mini/
  - src/assets/mini/

파일을 넣은 뒤 반드시:
  1. npm run dev 재시작 (Ctrl+C 후 다시 실행)
  2. 브라우저 Ctrl+Shift+R 새로고침

직접 확인:
  http://localhost:5173/images/mini/01.png
  (포트 번호는 터미널에 표시된 값 사용)
